# RecyclerView Interaction Test

[![Kotlin](https://img.shields.io/badge/Kotlin-1.8+-blue.svg?logo=kotlin)](https://kotlinlang.org)
[![Platform](https://img.shields.io/badge/Platform-Android-green.svg?logo=android)](https://www.android.com/)
[![RecyclerView](https://img.shields.io/badge/Component-RecyclerView-green.svg)](https://developer.android.com/develop/ui/views/layout/recyclerview)

Тестовое приложение для изучения интерактивных возможностей RecyclerView в Android. Демонстрирует различные типы взаимодействия с элементами списка.

## Функциональность

- Лайки элементов списка
- Перемещение элементов вверх/вниз
- Удаление элементов через PopupMenu
- Показ ID элемента по клику
- Загрузка изображений с Glide
- Observer pattern для обновления данных

## Технологии

- Kotlin
- RecyclerView
- Glide
- PopupMenu
- Observer Pattern
- ViewBinding
